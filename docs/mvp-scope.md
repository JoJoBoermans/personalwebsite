# MVP scope

## In scope

- One rectangular shelf/cabinet opening
- Internal width, height, and usable depth
- Centimetres and inches
- Horizontal and vertical clearances
- Up to 20 object definitions and 100 item instances
- Normal and base-rotated orientations
- Stackable and easy-access preferences as scoring inputs
- Compact, Easy Access, and Balanced layouts
- SVG visualization
- Text result summary
- Accessible selection and movement controls
- Undo, redo, and reset
- Last-project local save
- JSON import/export
- SVG or PNG export
- Print view
- Copyable measurement list
- Example project
- English static site and core guides
- Consent-gated GA4 integration contract
- Static Netlify deployment

## Explicitly out of scope

- Multiple shelves or connected compartments
- Drawer top-down mode
- Doors, hinges, pipes, sloped ceilings, and custom obstacles
- Round, tapered, or irregular objects
- Weight limits
- Real-world product catalogues
- Retailer links and affiliate logic
- Accounts, cloud sync, public share links, collaboration
- Camera measurement, computer vision, AR, 3D
- AI recommendations
- Background notifications
- Native applications
- Reviews or community content
- Advertisement placement

## Definition of validation-ready

The MVP is ready to test when a first-time visitor can complete the whole path from measurements to an understandable saved result without an account and without external data.
